# 🎨 Sovereign Seasons - Resource Pack (Módulo 5)

Server Resource Pack oficial para ambientación visual, iconos de interfaz, efectos climáticos y follaje estacional.

## Contenido:
- **Iconos de Interfaz (Custom Font Glyphs):** Iconos para Primavera, Verano, Otoño e Invierno en ActionBars, BossBars y menús de chat.
- **Follaje Estacional:** Variaciones de color en hojas de árboles, pasto y cultivos marchitos.
- **Estructura:** Compatible con Minecraft 1.20.4–1.21.x (`pack_format: 46`).
