# 🍲 Sovereign Seasons - Pantry (Módulo 2)

Módulo encargado de la conservación de alimentos, procesamiento y descomposición según la estación y temperatura ambiental.

## Funcionalidades Planificadas:
- **Descomposición estacional de alimentos:** Los alimentos se pudren más rápido en Verano si no están almacenados adecuadamente.
- **Bodegas subterráneas (Cellars):** Estructuras frías bajo tierra para prolongar la vida útil de las provisiones.
- **Sistemas de curado y conserva:** Salazón, ahumado y fermentación para preparar reservas alimentarias para el Invierno.
- **Integración con Core:** Consume `SovereignSeasonsApi` para consultar la estación actual y temperatura.
